# Guillaume Furminger — Portfolio

Static portfolio site for Guillaume Furminger, Executive Creative Director (Amsterdam).

- `index.html` — the whole site (HTML, CSS, JS in one file)
- `img/` — project imagery
- `vercel.json` — static hosting config for Vercel (no build step)

Deploy: import this repo in Vercel with framework preset **Other**, no build command, output directory `.`.
